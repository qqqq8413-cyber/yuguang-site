租借須知

取還、證件、逾期與賠償的處理方式

先看這五件事

  • 租期含取件日與歸還日：10/1 取件、10/2 歸還，計 2 天。
  • 取件時押一張證件（身分證或健保卡），並簽立本票；歸還點驗無誤後當場返還證件與本票。
  • 取還地點在屏東市中華路 80-1 號工作室，週一至週五 11:00–20:00，請先用 LINE 約時間。不提供宅配。
  • 網站送出的是租借需求；我們用 LINE 回覆確認後才算預約成立。
  • 器材頁標示的價格為未稅，需開立統一編號發票者另加 5%。

一、預約與確認

  1. 在器材租賃頁選好器材與日期、送出租借需求後，我們會在一個工作日內用 LINE 回覆，確認器材檔期與取件時間。
  2. 網站顯示的金額是預估金額，實際金額以 LINE 確認的報價為準。
  3. 收到我們的確認訊息後，預約才算成立。在那之前，器材仍可能被其他人預約。
  4. 週末與連假是熱門檔期，建議提前 3 天以上詢問。

二、租期計算

  1. 租期以「日」計算，含取件日與歸還日。
  2. 當日取件、當日歸還，以 1 天計算；最短租期為 1 天。
  3. 跨週末可以依實際使用情況彈性處理（例如週五取件、週一歸還），請在詢問時一併說明。

三、取件與歸還

  1. 地點：嶼光映像工作室，屏東縣屏東市公園里中華路 80-1 號。
  2. 時間：週一至週五 11:00–20:00，需事先以 LINE 約定時間。
  3. 不提供宅配，一律當面取件與歸還。
  4. 取件時請當面清點器材與配件，並確認外觀與功能正常。我們會拍照記錄出借時的狀態，歸還時以此對照。
  5. 歸還時請將器材、電池、配件依原狀放回收納包。電池不需充滿。
  6. 記憶卡請自備。若使用本工作室的記憶卡，歸還後資料會被格式化，請務必自行備份。

四、證件與本票

  1. 取件時請押一張證件：身分證或健保卡皆可，需為租借人本人的證件。
  2. 證件由我們保管至歸還，點驗器材無誤後當場返還。保管期間不影印、不拍照、不留存任何副本。
  3. 同時請簽立本票，金額依租借器材的價值認定，作為器材的擔保。器材完整歸還時，本票當場返還。
  4. 以公司名義租借者，請由實際取件人押證件並簽立本票；需要用印的租借單或報價單可以另外提供。
  5. 個人與公司都可以租借，不限定是同業或工作室。

五、付款與發票

  1. 租金於取件時付清，可用現金或轉帳。
  2. 器材頁標示的價格為未稅價。需要開立統一編號發票者另加 5%，請在確認訂單時提供公司抬頭與統一編號。
  3. 未定價的器材會標示「價格另計」，由我們在 LINE 確認時報價。

六、取消與改期

  1. 取消與改期一律免費，只要事先告知即可，不收取任何費用。
  2. 只是希望你盡早說：檔期空下來，其他人才租得到。
  3. 遇颱風、豪雨等天災，政府宣布停班停課時，可免費改期或取消。
  4. 若因我們的原因（器材故障、檔期重疊）無法出借，將全額退費並協助尋找替代方案。

七、逾期歸還

  1. 請於約定時間歸還。需要延長租期時請提前以 LINE 告知，我們會確認器材是否能延長，延長的日數以原日租計費。
  2. 未事先告知而逾期者，每逾期 1 天加收當日租金的 1.5 倍。
  3. 逾期超過 7 天且無法聯繫者，將依本票與相關法令處理。

八、使用與保管

  1. 器材僅限租借人本人或其團隊使用，不得轉租或轉借。
  2. 請依器材原廠說明操作。不熟悉的器材可以在取件時請我們示範，例如穩定器調平衡。
  3. 請避免在雨中、海邊、沙地、高溫車內等環境無防護使用，也請勿讓器材淋雨、落水或受潮。
  4. 不得自行拆解、改裝或送修。使用中發生異常，請立即停止使用並以 LINE 聯繫我們。
  5. 空拍、水下或其他特殊場地使用，請在租借前先告知。

九、損壞與遺失

  1. 歸還時由雙方當面檢查，若有損壞，依以下原則處理：
    1. 正常使用的輕微磨損：不收費。
    2. 可維修的損壞：由租借人負擔原廠或合作維修廠的實際維修費用，並補償維修期間無法出租的租金損失（以維修天數 × 日租金計算，上限 7 天）。
    3. 無法修復或遺失：依器材當時市價賠償。
  2. 配件（電池、充電器、背帶、鏡頭蓋、收納包等）遺失者，依原廠售價賠償。
  3. 賠償方式與期限依租借合約約定；未能履行時，依本票處理。
  4. 高價器材建議租借人自行投保器材險。

十、免責說明

  1. 器材出借前都經過檢查，但無法保證拍攝過程中完全不發生故障。重要拍攝請自行準備備援方案。
  2. 因器材故障造成的拍攝損失（場地、人員、檔期等費用），本工作室不負賠償責任，以退還該器材租金為限。
  3. 記憶卡中的拍攝資料請自行備份，本工作室不負資料遺失責任。

十一、個人資料

  1. 你在租借時提供的姓名與 LINE ID，僅用於確認訂單、聯繫取還與處理租借相關事務，不會提供給第三方。
  2. 取件時押的證件不影印、不拍照、不留存副本，歸還時當場返還。
  3. 租借紀錄（姓名、聯絡方式、器材與日期）保留一年後刪除，法令另有規定者除外。
